# Six-image APEX pilot

Brand: Data Science Masterminds

Program treatment: Agentic Accelerator

Authors: Kunaal Naik & Arpan Saxena

This pilot implements six concepts from the 100-image plan presented in chat. All six use the supplied Accelerator APEX identity to evaluate one consistent visual system. Master Class and Founder variants are not included.

## Images and teaching notes

| Concept | Image | Learning point | Qualification / discussion prompt |
| --- | --- | --- | --- |
| 004 | [Model versus application](004-model-vs-application.png) | The model is one component of a usable application. | The engine/car comparison is an analogy. An application can use several models and external services. Ask: what does the application supply beyond the model? |
| 021 | [Training versus inference](021-training-vs-inference.png) | Training updates model parameters; inference uses the trained model. | Cooking is an analogy. Context updates and stored memories during use are not automatically parameter training. Ask: is supplying a document the same as retraining? |
| 040 | [Retrieval-augmented generation](040-retrieval-augmented-generation.png) | Retrieve relevant information, add context, then generate a response. | Retrieval and generation can both fail; source relevance and answer support still need checking. Ask: what if the retrieved passage is outdated? |
| 060 | [Agent loop](060-agent-loop.png) | Observe, decide, act, and repeat or exit within constraints. | This is a simplified operating loop, not a universal architecture. Agents require explicit permissions, budgets, and stopping conditions. Ask: when should the system ask a person? |
| 091 | [Unit economics](091-unit-economics.png) | Revenue less variable costs gives contribution, not net profit. | The $100 revenue, $40 variable cost, and $60 contribution are hypothetical. Fixed costs and taxes remain. Ask: which delivery and support costs vary with each sale? |
| 095 | [Effective delegation](095-effective-delegation.png) | Specify the outcome, boundaries, and human review point. | A written boundary is not a substitute for enforced access controls. Ask: what permissions would enforce “do not send”? |

## Visual system

- Landscape compositions designed for 16:9 presentation use.
- Deep navy / near-black background, white text, amber emphasis, and teal details.
- Space Grotesk-like headings and Inter-like body typography; lettering is rasterized, not installed-font text.
- One takeaway, a dominant illustration or diagram, and restrained attribution.
- Every image includes the company, program, and both authors.
- Standalone PNGs contain flattened artwork and typography. They are pilot images, not editable PowerPoint slides.
- All six native PNGs are 1672 × 941, approximately 16:9. They have not been upscaled to 1920 × 1080.

## Review standard

Visual review completed for all six: exact author spelling, concept labels, readable text, factual distinctions, and agent-loop arrow direction. Files were checked for PNG dimensions and archive integrity. Human audience comprehension and projector readability still require a live pilot. Image-generation output differs slightly in typography and layout across slides; editable composition is the recommended next step for the full library.
