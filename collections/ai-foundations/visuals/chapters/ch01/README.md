## Teaching qualifications

- **001 — Artificial intelligence:** AI is a broad category; the three capabilities illustrate common tasks rather than an exhaustive definition.
- **002 — Machine learning:** The fruit example illustrates pattern learning. Machine learning still requires algorithms, objectives, and human design choices.
- **003 — Generative AI:** Generated content is not guaranteed original, accurate, or suitable for every use; review results.
- **004 — Model versus application:** Engine/car is an analogy. An application can use several models and external services.
- **005 — Prediction versus generation:** Prediction and generation are contrasted by task. Generative models can themselves use next-token prediction.
- **006 — Multimodal AI:** Supported input/output modes vary by model and application. The diagram is conceptual, not a product capability claim.
- **007 — Hallucination:** Unsupported does not necessarily mean false; verification needs evidence appropriate to the claim.
- **008 — Human augmentation:** Driving is an analogy for allocating responsibility; no autonomous-driving capability is implied.
