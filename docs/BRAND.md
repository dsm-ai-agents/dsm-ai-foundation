# Shared brand and visual direction

Company: **Data Science Masterminds**. Authors: **Kunaal Naik & Arpan Saxena**.

Use the appropriate program label: AI Agent Master Class, Agentic Accelerator, or Agentic Founder. The program is independent of the research subject. Store any collection-specific treatment in its production brief.

| Treatment | Direction |
| --- | --- |
| Shared simple explainer | Deep navy / near-black, white text, generous space, plain language, one main idea, subtle lighting, familiar objects or consistent friendly characters where useful. |
| Agentic Accelerator APEX | Navy `#041B36`, near-black `#020B18`, white `#F7F8FC`, amber `#F2A541`, teal `#5EC4B6`; Space Grotesk headings and Inter body direction. |
| Agentic Founder income collection | Evergreen `#142823`, near-black green, ivory-white, amber `#F4B544`, muted teal; practical work imagery and decision-oriented explanations. |
| AI Agent Master Class | Use the shared direction until a specific program treatment is selected. |

Default composition is 16:9. Aim for 1920 × 1080 exports when supported; preserve and report actual native dimensions. Existing collections are 1672 × 941. Never claim that raster text is editable typography.

Every standalone visual carries the company, program, and author names in restrained attribution. Keep headlines readable, avoid crowding and decorative charts, label analogies and hypothetical figures, and retain qualifications in written content. Apple-inspired means clarity and restraint, not logos or affiliation.

For future web use, store images separately from meaningful page text. For editable slides, compose artwork and text as separate layers. Existing flattened PNGs remain valid teaching assets and should not be regenerated solely to change storage layout.
