## Teaching qualifications

- **077 — Document workflows:** Keep source references and require review of the resulting brief; generated summaries may omit or distort material.
- **078 — Data-analysis workflows:** Check calculations with deterministic tools and verify data definitions, assumptions, and provenance. The table is illustrative, not measured data.
- **079 — Decision dashboards:** Stock low is a hypothetical illustration. Define a threshold and responsible owner before applying a dashboard recommendation.
- **080 — Multimedia production workflows:** Production includes briefing, asset generation, editing, and review. Check rights, factual claims, and consistency before publication.
- **081 — HR and recruitment support:** The example supports scheduling and document preparation. It does not endorse automated candidate selection or removing human accountability.
- **082 — Finance exception handling:** A match flag is not automatic permission to pay. Investigate discrepancies, and keep financial controls and approval requirements.
- **083 — Operations and project coordination:** The dependency line is illustrative. Clarify dependency direction and assign ownership and escalation rules in the actual project system.
- **084 — AI-assisted software delivery:** The workflow is simplified; real software delivery also requires security, accessibility, maintenance, and rollback planning. AI assistance does not remove testing responsibilities.
