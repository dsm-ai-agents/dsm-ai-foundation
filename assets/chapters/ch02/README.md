## Teaching qualifications

- **009 — Structured and unstructured data:** Unstructured content can contain internal structure and structured metadata. The spreadsheet values are illustrative.
- **010 — Data quality:** Good inputs improve the basis for a result but do not guarantee correctness. The recipe is an analogy, not a tested cooking instruction.
- **011 — Features and labels:** These features are illustrative and are not sufficient to uniquely identify all fruit. Labels can also contain errors.
- **012 — Sampling bias:** Sampling bias concerns how a sample is selected and represented, not simply whether it is small.
- **013 — Privacy and consent:** Consent is not the only possible lawful basis. Appropriate use also depends on purpose, contracts, law, and organizational policy.
- **014 — Probability and uncertainty:** The forecast is illustrative. It supplies no numerical probability or real weather prediction.
- **015 — Correlation versus causation:** The example illustrates a possible shared cause. Correlation alone cannot establish the causal mechanism.
- **016 — Data visualization:** The data are hypothetical. Both table and chart show Monday 2, Tuesday 4, Wednesday 3; Tuesday is highest.
