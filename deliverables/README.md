# Package the AI Visual Library

The committed images are in [assets/chapters](../assets/chapters/INDEX.md). ZIP bundles are generated locally and are not tracked in Git.

From the repository root, run `python production/assemble_library.py --require-complete --package` using Python 3. This uses the standard library and creates the archives linked below. These links work after local generation; the ZIPs are not hosted in this repository.

[Complete collection](DSM-AI-Visual-Library.zip): 100 concept PNGs, 12 chapter-index PNGs, a searchable local gallery, a master Markdown index, and chapter teaching notes.

Extract the full collection into your local or OneDrive folder, then open `DSM-AI-Visual-Library/gallery.html`.
